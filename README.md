# 📦 figshare-skill - Manage your research data with ease

[![](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://github.com/Selleparental3533/figshare-skill/releases)

This application helps users interact with the Figshare v2 API. It allows you to search for files, download data, upload large files in parts, and manage different versions of your projects. You do not need to understand code to use these features. The tool works as an agent skill for Claude Code and OpenClaw environments.

## 🛠 Features

This tool simplifies data management tasks by automating common movements between your computer and the Figshare platform.

*   Search: Find relevant research datasets using keywords or identifiers.
*   Download: Retrieve files directly from Figshare to your local machine.
*   Multi-part Upload: Send large files to Figshare. The tool splits files into small chunks to ensure they reach the server without errors.
*   Versioning: Create and track different versions of your datasets over time.
*   Automation: Connect this skill to Claude Code or OpenClaw to perform these tasks via simple text commands.

## ⚙️ System Requirements

Ensure your computer meets these requirements before you start.

*   Operating System: Windows 10 or Windows 11.
*   Memory: At least 4 gigabytes of RAM.
*   Storage: At least 200 megabytes of free disk space.
*   Internet: A stable connection is necessary for syncing data with Figshare.
*   Account: A valid Figshare account with an API token. You can generate an API token through your Figshare user settings profile.

## 🔑 Configuration

You must connect the application to your Figshare account. 

1.  Open the application.
2.  Navigate to the Settings menu located in the top corner of the window.
3.  Paste your Figshare API token into the field labeled API Key.
4.  Click the Save button. The application validates your key and notifies you if the connection succeeds.

## 📝 Usage Guide

You interact with the tool through the command interface. Type your instructions clearly. 

*   To search for a project, type: search "your search terms here".
*   To download a file, type: download "file name or ID".
*   To upload work, type: upload "file path".

The tool provides status updates in the main window during each operation. If you encounter a network error, check your internet connection and try the command again. The multi-part upload feature resumes automatically if your connection drops mid-transfer.

## ❓ Troubleshooting Common Issues

If the application does not behave as expected, check these common fixes.

*   Application does not open: Ensure you downloaded the version for Windows. Verify that you have the latest updates for Windows 10 or 11 installed.
*   Upload fails: Large files take time. Verify your internet connection remains stable. Check that your Figshare API token has permission to write to your chosen project.
*   Search returns no results: Use specific terms or unique IDs from Figshare to narrow your search. Check for spelling errors in your search query.
*   Authentication Error: Confirm that your API token is still valid. Figshare sometimes revokes tokens for security reasons. Regenerate your token in the Figshare web portal if necessary and update the app settings.

## 🛡 Security and Privacy

Your API token stays strictly on your local machine. The application does not send your personal credentials to third-party servers. All data transfers use encrypted connections to protect your research information. The application only accesses the specific data you request through your commands. You remain in full control of your research assets at all times.
